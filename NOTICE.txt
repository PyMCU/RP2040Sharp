2. RP2040 bootrom — embedded binary
-------------------------------------------------------------------------------

RP2040Sharp embeds the RP2040 bootrom images so the emulator can execute the real
on-chip ROM code that firmware calls by fixed address. These are the silicon ROMs
of the chip — not firmware, and not authored by this project.

Embedded resources (compiled into the RP2040Sharp assembly):

    src/RP2040Sharp/bootrom_b1.bin   RP2040 B0/B1 silicon (bootrom version 2)
    src/RP2040Sharp/bootrom_b2.bin   RP2040 B2 silicon (bootrom version 3)

Copyright (C) 2020 Raspberry Pi Trading Ltd. (as stated in the ROM images)

    Upstream: https://github.com/raspberrypi/pico-bootrom

The bootrom is licensed under the 3-clause BSD licence, reproduced verbatim below
from the upstream LICENSE.TXT.

IMPORTANT — the floating point library has been REMOVED from the images we ship.
As the notice at the top of the licence states, the upstream licence does not cover
bootrom/mufplib.S and bootrom/mufplib-double.S. Those files carry a separate
licence (Copyright (c) 2020 Mark Owen, https://www.quinapalus.com) permitting use
"solely on a Raspberry Pi RP2040 device", or GPLv2 from their author. Neither
permits redistributing them here, so tools/strip_mufplib.py blanks that code out of
both images before they are packaged, and RP2040Sharp implements the ROM float API
natively instead (see src/RP2040Sharp/Peripherals/BootromFloat.cs). No mufplib code
is present in this repository or in any published package. Everything that remains
in the images is covered by the BSD licence below.
